Decision layer

120 ADC items, 32 frames, Qwen3.8-27B. Only the way the decision is produced changes.

Summary

  • D1 (Qwen's own option probabilities): same accuracy as generated text, 4.8× faster, usable confidence.
  • D2 (zero-shot text decision model on Qwen's description): Matching at chance.
  • D3 (same model fine-tuned on VALU): 95 / 100 / 100 %, but 92.5 / 100 / 100 % without the description. It learnt the options, not the video.
  • Edge detectors and the real-trigger replay: see the Edge detector page.

Protocol and run ids
  • Protocol valu_demo_v1_decision: frozen manifest, cached frames and prompt of the generative runs. D0–D2 untrained; D3 trained on VALU videos disjoint from the evaluation and smoke sets (valu-demo-v1-decision-train).
