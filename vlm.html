Protocol and run ids
  • VALU demo subset v1, adapted protocol: 32 frames uniform over the whole video (long edge ≤ 672 px), BF16, greedy decoding, batch size 1, one H200; failures count as wrong. Not comparable with the VALU paper's numbers.
  • Runs: Qwen3.8-27B = evaluation-qwen38_27b-9e291ee519 (Qwen/Qwen3.8-27B); Qwen3-VL-8B-Instruct = evaluation-qwen3vl_8b-f66a0edc80 (Qwen/Qwen3-VL-8B-Instruct); VideoLLaMA3-7B = evaluation-videollama3_7b-fdf9f0551c (DAMO-NLP-SG/VideoLLaMA3-7B);
  • Decision heads (protocol valu_demo_v1_decision, same items and frames): D0 generative = evaluation-qwen38_27b-9e291ee519; D1 letter logits = evaluation-qwen38_27b+letters-04b42426c0; D2 Laya typed-decisions = evaluation-qwen38_27b+laya_td-f6b42401e8; D2′ Laya root = evaluation-qwen38_27b+laya_root-c348c93694; D3 Laya fine-tuned (VALU) = evaluation-qwen38_27b+laya_ftv-db238237c1; D3 trained on manifest valu-demo-v1-decision-train; controls with another item's description are in the run records.
