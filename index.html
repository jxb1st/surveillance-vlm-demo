Can server-side Video VLMs resolve ambiguous surveillance events using temporal context and relationships?

An edge detector flags an uncertain event, a relevant video window is sent to a server, and a Video VLM analyzes the event using temporal and relational evidence. This page explains that workflow and replays it on real footage.

Proposed workflow

In this version the edge side is a scripted replay. The server side is real: every server output shown below was produced by running the model on exactly the window shown.
