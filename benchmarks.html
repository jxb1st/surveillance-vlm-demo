VALU tasks

ADC · Anomaly Description Choice

Pick one description of the video.

Matching · one option is rightExclusion · none is rightRejection · video is normal

Metric accuracy per subtask

TDG · Temporal Description Grounding

Given a description, find its time interval.

Metric temporal IoU, recall at IoU ≥ 0.3, 0.5, 0.7

ALD · Anomaly Localization and Description

Find and describe the anomaly at a requested level.

Metric qualitative only in v1

Five abnormal semantic levels

Normal-event records keep their own source label, Normal_Event. They are not folded into an abnormal level.

Eligibility
Sources UCF, ECVA; source duration ≤ 300 s; decodable matched media; documented label semantics; verified time mapping (TDG/ALD single span inside media).
Selection rule
Within each stratum, records are ordered by SHA-256 of (dataset_revision | source_video_id | task | raw_record_locator | seed | role salt); one record per video per stratum; quotas spread evenly over ADC subtasks, then semantic levels, then sources; shortfalls are redistributed in sorted stratum order.
Shortfalls
None. Every target quota was met.
Development data
11 smoke questions on 11 videos, disjoint from the evaluation videos, were used to debug prompts and parsers.
This subset is a documented demonstration subset. It is not statistically representative of CCTV behavior, and it is not a reproduction of the full VALU benchmark.
