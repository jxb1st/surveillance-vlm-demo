Benchmarks

What the benchmark tests, where its videos come from, and which documented subset is evaluated in this demo.

Three different things that are often confused

Original video source

The footage itself, for example UCF-Crime or ECVA. Several benchmarks reuse the same videos, so overlap is judged by source-video identifiers and file hashes, not by dataset names.

Language annotation collection

Descriptions, questions or structured labels written for existing videos, for example UCA or FineW3. A collection can be released without any playable video.

Benchmark evaluation task

A fixed input, a reference answer and a metric, for example the three VALU tasks below. Only this gives a score.

VALU tasks

ADC · Anomaly Description Choice

Given a video and task-specific candidate descriptions, select one answer.

  • Matching: one candidate is the reference description (abnormal video, options A–G).
  • Exclusion: every specific description is wrong; the correct choice is “anomaly present, but none of the descriptions is correct” (abnormal video, options A–F).
  • Rejection: the video is normal and the descriptions are of non-existent abnormal events; the correct choice is “no abnormal occurrence” (options A–F).

In the imported records the correct Exclusion option is always E and the correct Rejection option is always F. A model that always answers E or F would score perfectly on that subtask, so the three subtasks are reported separately and never pooled.

Metric exact answer-ID accuracy per subtask.

TDG · Temporal Description Grounding

Given a video and a textual description, predict the time interval in which the described event occurs.

Metric temporal IoU, recall at IoU ≥ 0.3, 0.5, 0.7. v1 uses records with one verified, non-empty reference span.

ALD · Anomaly Localization and Description

Given a video and a requested semantic level, localize and describe the relevant anomaly. No description or time is supplied to the model.

Metric qualitative only in v1. No description score is computed.

Five abnormal semantic levels

Normal-event records keep their own source label, Normal_Event. They are not folded into an abnormal level.

What this benchmark does not show

Fine-grained descriptions do not automatically cover paired ambiguities such as fighting versus play, or falling versus voluntarily lying down. A model can score well here without being tested on those pairs. Claims about such pairs need verified paired examples, which this subset does not contain.
